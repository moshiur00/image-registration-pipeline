# Week 8 R3 holdout intake boundary

This directory is intentionally empty of source pixels. R3 is a new confirmatory cycle; the exposed R2 source and every copy, rename, transcode, or lineage-relative derivative of it are permanently ineligible.

Do not preview, decode, transform, or otherwise inspect a candidate here before all of these conditions are met:

1. the corrected evaluator, integrity gates, and reporting contract pass renewed G3 and G5;
2. a data custodian establishes provenance, permitted use, canonical identity, complete lineage, and project independence for a genuinely new source;
3. the candidate is checked against `configs/week08_r3_source_use_ledger.json` by path, byte hash, canonical identity, and lineage;
4. a versioned R3 G6 enrollment record and manifest are created; and
5. a release reviewer grants a new, one-run G7 authorization.

The only permitted R3 output roots are:

- `outputs/week08_r3_holdout/`
- `outputs/week08_r3_final/`
- `outputs/week08_r3_archives/`

Nothing under `data/holdout/week08/`, `outputs/week08_holdout/`, `outputs/week08_final/`, or `outputs/week08_archives/` may be copied into or executed as part of R3. The current empty state is a deliberate gate, not missing data.
